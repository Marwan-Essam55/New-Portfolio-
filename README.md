Welcome to my official developer portfolio! This responsive web application highlights my background as a **Full Stack Software Engineer (.NET & React)**, showcasing my projects, technical skills, certifications, and academic background.


---

## ✨ Key Features

- 📱 **Fully Responsive:** Customized layout for Mobile, Tablet, and Desktop with an optimized mobile hamburger navigation menu.
- ⚡ **Interactive UI & Animations:** Smooth scroll-triggered transitions, glassmorphic UI elements, and a continuous typewriter hero effect.
- 🎯 **Direct Messaging:** Instant direct links to Gmail compose and WhatsApp chat.
- 📄 **CV Integration:** Direct high-speed download link for my resume via Google Drive.
- 🛠️ **Categorized Showcase:** Clear distribution of Technical Skills, Projects, Education, and Certifications.
